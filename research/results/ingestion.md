# Phase 1 — Ingestion: measured accuracy

Date: 2026-09-07 · Runner: `python backend/cli.py evaluate-ingestion --corpus data/synthetic-corpus`
· Raw numbers: [`ingestion.json`](./ingestion.json) (generated in the same run)

## ⚠️ Read the caveat first

**Every score below is 1.0, and that is a limitation of the corpus, not a claim of quality.**

`research/corpus/` is empty — the plan (doc 05, exit criteria: *"20+ corpus
documents parse"*) assumes a pile of real theses, and none are available in this
checkout. So the corpus here is **synthetic**: six documents generated by
`backend/tests/factories.py`, i.e. by the same person who wrote the parsers that
read them. A perfect score against fixtures you authored yourself proves the
parsers are self-consistent; it says nothing about how they behave on a real
university template, a scanned PDF, or a thesis written in Microsoft Word 2003.

Treat the numbers as **regression anchors** ("the pipeline still extracts
everything it used to"), not as accuracy estimates. The methodology is
nevertheless complete and will produce honest numbers the moment a real corpus
is dropped in — no code change needed, only data.

**The PDF target (F1 > 0.75) is therefore unverified, not met.**

One expected parse warning, emitted exactly as designed:

- `report-latex` → `\tableofcontents present: rendered ToC/list not represented
  in the IR`. The parser never runs a TeX engine, so it cannot know how the ToC
  will be typeset; it records the fact instead of guessing. This is the intended
  behaviour (doc 02 §3: *measure imperfection, never hide it*).

## What is actually being measured

`metrics.py` compares the parser output against a hand-written `.expected.json`
sidecar per document:

- **heading F1** — multiset match on `normalise_text(text) + "@" + level`, so a
  heading with the wrong text *or* the wrong level is a miss.
- **section F1** — multiset match on `Section.kind` (the 13-value `SectionKind`
  enum), which is what downstream analysers actually consume.
- **citation F1** — multiset match on expanded citation keys (`\cite{a,b}` counts
  as two).
- **reference accuracy** — fraction of per-reference expectations satisfied
  (`year`, `doi`, `first_author` substring), not a mere count.
- **figure / table recall** — floats registered by caption, cross-checked against
  `referenced_by`.

Because the sidecars are written by hand from the source documents rather than
dumped from parser output, a silent parser regression *would* show up as a
regression here. That is the value of the harness even with a synthetic corpus.

## Known gaps and honest limitations

1. **No real theses.** Everything above is synthetic. The doc 05 exit criterion
   "20+ corpus documents parse" is **not met** and cannot be met in this
   checkout. This is the single biggest open item for Phase 1.
2. **PDF accuracy is unproven.** `thesis-pdf` is a clean, digitally-authored PDF
   with real ToC bookmarks and consistent fonts — the easy case. Real-world
   failures (scanned pages, no embedded fonts, two-column layouts, headings
   typeset at body size but bolded) are unexercised. The `> 0.75` target should
   be treated as untested.
3. **DOCX page counts** come from `docProps/app.xml`, which Word writes and other
   tools may omit; a missing value yields 0 pages rather than a failure.
4. **LaTeX has no page numbers at all** — a structural consequence of the
   no-TeX-engine constraint. Any analyser that needs page-localised evidence must
   fall back to block locators (line numbers are preserved).
5. **`thebibliography` vs `.bib`** are both covered, but BibLaTeX with complex
   cross-refs, `@set` entries, and `biber`-only features are not.

## Reproduce

```bash
.venv/bin/python research/scripts/make_synthetic_corpus.py
.venv/bin/python backend/cli.py evaluate-ingestion \
    --corpus data/synthetic-corpus --out-json research/results/ingestion.json
```

The corpus lives in `data/synthetic-corpus/` and is gitignored; it is regenerated
from `backend/tests/factories.py`, so the fixtures and the measured corpus can
never drift apart.
