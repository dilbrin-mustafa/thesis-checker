# Thesis corpus (Phase 0, week 2 — do not skip)

Target: **20–30 real theses** — PDF, DOCX, LaTeX; Polish and English;
ideally PG / your faculty.

Sources: PG MOST Wiedzy, faculty pages, supervisor, colleagues (with
permission), other PL open repositories.

- Put documents in `research/corpus/documents/` (git-ignored — never commit
  real theses; they contain personal data).
- Record provenance in `LICENSE-AND-CONSENT.md` (which repo/person/licence).
- Hand-annotate 5: section boundaries, heading levels, citation spans,
  reference list → this is the ingestion test set (Phase 1 exit criterion).

> Every hour here saves five in Phase 1. Real theses contain rotated pages,
> embedded Visio diagrams, mixed-language tables, hand-broken equations.
